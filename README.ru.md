# AnimeBox

[English](README.md) | **Русский**

Локальная библиотека аниме для русскоязычных сайтов. Ищите тайтлы, выбирайте озвучку, смотрите в браузере или
скачивайте серии, чтобы смотреть без интернета. AnimeBox работает на вашем компьютере, хранит серии обычными файлами и
не требует аккаунтов и облака.

> Сайты-источники меняются без предупреждения. Рекомендуемый и лучше всего проверенный источник — AnimeGO; остальные
> помечены как экспериментальные. Реальное состояние каждого источника видно в **Настройки → Источники**.

## Возможности

| | |
|---|---|
| Поиск | Несколько источников параллельно; медленный или сломанный источник не блокирует остальные, ответ каждого виден |
| Страница тайтла | Описание, серии, озвучки с их плеерами, прогресс просмотра и офлайн-статус каждой серии |
| Просмотр | Встроенный плеер: сохранение и восстановление позиции, горячие клавиши, качество, скорость, смена озвучки, аудиодорожки и субтитры (если они есть в потоке), автопереход к следующей серии |
| Надёжность | Если один плеер озвучки не работает (например, CVH), пробуется следующий (Kodik, Aniboom, …); устаревший поток переполучается без потери позиции |
| Загрузки | Серия или весь сезон, параллельная очередь, реальные прогресс и скорость, повторы, отмена; пауза и продолжение для прямых MP4 |
| Библиотека | Только серии, которые реально есть на диске; занятое место, сортировка, фильтр, удаление, пересканирование |
| Офлайн | Скачанные серии, постеры и прогресс работают без интернета, даже если источник недоступен |
| Steam Deck | Linux-сборка запускается на SteamOS; по желанию — сжатие в H.265 для экономии места |

### Источники

| Источник | Статус | Примечание |
|---|---|---|
| AnimeGO | **Стабильный**, по умолчанию | Много озвучек; у каждой несколько плееров с автоматическим переключением |
| AniLiberty (AniLibria) | Экспериментальный | Только собственная озвучка |
| AnimeVost | Экспериментальный | Только собственная озвучка; прямые MP4 (загрузку можно ставить на паузу) |
| Yummy Anime | Экспериментальный | Часть плееров — только DASH: можно скачать, но не смотреть в браузере |
| AniLib, DreamCast, SameBand | Экспериментальные, выключены по умолчанию | Небольшие или зависящие от региона каталоги |

HDRezka больше не предлагается: её экстрактор обходит антибот-проверку. AnimeBox не обходит CAPTCHA и другие
ограничения доступа.

## Установка (portable, рекомендуется)

Скачайте архив для своей системы в [GitHub Releases](https://github.com/endercodezz/AnimeBox/releases).
Python, Node.js и FFmpeg уже внутри — больше ничего ставить не нужно.

| Архив | Запуск |
|---|---|
| `AnimeBox-<версия>-Windows-x64.zip` | Распакуйте, откройте `AnimeBox.exe` |
| `AnimeBox-<версия>-Linux-x64.tar.gz` | Linux x86_64 и Steam Deck: распакуйте, затем `./AnimeBox` |
| `AnimeBox-<версия>-macOS-x64.zip` | Mac на Intel: распакуйте, откройте `AnimeBox` |
| `AnimeBox-<версия>-macOS-arm64.zip` | Apple Silicon: распакуйте, откройте `AnimeBox` |

AnimeBox запускает приватный сервер на `http://127.0.0.1:8787` и открывает браузер. Закрытие вкладки его не
останавливает — используйте кнопку **Остановить** в боковой панели, чтобы случайно не прервать загрузки.

Проверка архива по контрольным суммам: `sha256sum -c SHA256SUMS.txt --ignore-missing`.

**macOS:** неподписанной сборке при первом запуске может понадобиться **Control-клик → Открыть**. Если загрузки
падают с `ffmpeg failed`, выполните в папке AnimeBox `bash scripts/grant-macos-permissions.sh` (флаг
`--clear-quarantine` — только для архивов из источника, которому вы доверяете).

## Обновление с 1.x

Ваши данные лежат в трёх местах, остальное хранить не нужно:

- `.env` — настройки (файлы из 1.x работают без изменений);
- `data/` — база данных (история, прогресс, история загрузок, настройки);
- `library/` — скачанные серии и постеры.

**Portable:** распакуйте новую версию и перенесите эти три элемента из старой папки в новую (с заменой пустых).
**Из исходников:** `git pull`, затем снова запустите скрипт установки.

При первом запуске AnimeBox 2.0:

1. копирует базу в `data/backups/animebox-v0-<дата>.db`;
2. объединяет дубли, появившиеся из-за ошибки с идентификаторами в 1.x, сохраняя лучший прогресс;
3. переводит сохранённые пути в относительные к библиотеке;
4. перестаёт считать просто открытые тайтлы содержимым библиотеки (файлы не удаляются);
5. удаляет пустые папки и брошенные файлы `*.part.*`, оставленные в `library/` версией 1.x.

Если что-то пойдёт не так, миграция откатывается, а копия остаётся в `data/backups/`. Серии, которые есть в базе, но
отсутствуют на диске, скрываются из библиотеки; **Библиотека → Пересканировать** удаляет такие записи и находит серии,
скачанные AnimeBox ранее, но выпавшие из учёта.

## Запуск из исходников

Нужны Python 3.12+, Node.js 20+, Git и FFmpeg в `PATH`. Docker не используется. Скрипт установки скачивает
закреплённый проверенный коммит [anicli-api](https://github.com/vypivshiy/anicli-api) в `.references/anicli-api` и
применяет патч совместимости из `patches/`.

```powershell
# Windows
git clone https://github.com/endercodezz/AnimeBox.git
cd AnimeBox
.\scripts\install.ps1
.\scripts\run.ps1
```

```bash
# macOS / Linux / Steam Deck
git clone https://github.com/endercodezz/AnimeBox.git
cd AnimeBox
./scripts/install.sh
./scripts/run.sh
```

В Windows можно запускать двойным щелчком: `scripts\install.cmd`, `scripts\run.cmd`, `scripts\check.cmd`.
Режим разработки с горячей перезагрузкой: `run.ps1 -Dev` / `run.sh --dev` (интерфейс на `http://127.0.0.1:5173`,
документация API — `http://127.0.0.1:8787/docs`).

## Настройка

`.env` создаётся из `.env.example` при первом запуске и никогда не перезаписывается. Большинство параметров есть и в
**Настройках** (значения из интерфейса важнее). Основное:

| Параметр | Назначение |
|---|---|
| `LIBRARY_PATH`, `DATA_PATH` | Где лежат серии и база (относительно папки AnimeBox) |
| `HTTP_PROXY` | HTTP- или SOCKS-прокси для поиска, просмотра **и** загрузок |
| `PROVIDER_SEARCH_TIMEOUT`, `PROVIDER_DETAIL_TIMEOUT`, `PROVIDER_STREAM_TIMEOUT` | Лимиты времени на этапы для каждого источника |
| `PREFERRED_VOICEOVERS` | Приоритет озвучек для автовыбора |
| `DEFAULT_QUALITY` | 360, 480, 720 или 1080 — ближайшее доступное качество не выше указанного |
| `MAX_CONCURRENT_DOWNLOADS` | Одновременных загрузок (1–6) |
| `ALLOWED_HOSTS` | Дополнительные имена хоста помимо `127.0.0.1`/`localhost` |

## Горячие клавиши плеера

| Клавиша | Действие |
|---|---|
| Пробел / K | Пауза / воспроизведение |
| ← / → | −5 с / +5 с |
| J / L | −10 с / +10 с |
| ↑ / ↓ | Громкость |
| M | Без звука |
| F | Полный экран |
| Shift+N / Shift+P | Следующая / предыдущая серия |
| < / > | Медленнее / быстрее |
| 0–9 | Переход к 0–90 % |
| / или Ctrl+K | Поиск (вне плеера) |

Клавиши работают и в русской раскладке.

## Где хранятся данные

```text
library/
└── Название аниме/
    ├── poster.jpg
    ├── metadata.json          # содержит идентификатор AnimeBox — нужен для пересканирования
    └── Season 1/
        ├── Episode 01.mp4
        └── Episode 02.mp4
data/
├── animebox.db                # SQLite: история, прогресс, очередь, настройки
├── backups/                   # автоматические копии перед обновлением схемы
├── provider_health.json
└── search_cache/
```

## Архитектура

```text
backend/
├── api/          # FastAPI-роутеры: каталог, загрузки, библиотека, история, система
├── providers/    # движок источников над anicli-api: реестр, плееры, здоровье, кэш, HTTP-сессии
├── player/       # медиасессии и прокси с переписыванием HLS
├── downloader/   # очередь, параллельность, проверка, атомарное завершение
├── services/     # файлы и индекс библиотеки, настройки, ffmpeg
├── database/     # async SQLAlchemy и версионные миграции
├── models/  schemas/
frontend/src/
├── api/  lib/  components/  pages/  pages/player/
```

Бэкенд: Python, FastAPI, async SQLAlchemy, SQLite, Pydantic, httpx. Фронтенд: React, TypeScript, Tailwind CSS, Vite,
hls.js.

## Решение проблем

**Поток не открывается.** Плеер перебирает все плееры выбранной озвучки и показывает, какие не сработали. Выберите
другую озвучку или откройте **Настройки → Источники → Проверить**, чтобы увидеть, на каком этапе сбой (поиск, тайтл,
серии, озвучки, поток).

**Источник «не отвечает».** Сайт может быть недоступен из вашей сети или изменился. Результаты остальных источников
всё равно показываются. Если источник работает только через прокси, укажите его в **Настройки → Сеть** — он будет
использоваться и для поиска, и для просмотра, и для загрузок (некоторые видеохостинги привязывают ссылки к IP).

**«Данные тайтла устарели».** Источник больше не узнаёт сохранённую ссылку — найдите тайтл поиском заново.

**Загрузки падают с ошибкой ffmpeg.** При запуске из исходников установите FFmpeg и проверьте `ffmpeg -version`. В
portable-сборках FFmpeg уже есть; **Настройки → Диагностика** показывает, какой бинарник используется.

**В библиотеке меньше серий, чем раньше.** Серии с удалёнными или перемещёнными файлами скрываются. Используйте
**Библиотека → Пересканировать**.

**Логи.** Portable-сборка пишет `data/animebox.log`; при запуске из исходников логи идут в терминал. Пароли прокси и
подписи в ссылках маскируются.

## Правовые сведения

AnimeBox — локальный клиент, он не размещает медиаконтент. Используйте его только с источниками и материалами,
разрешёнными законом и условиями сервисов. Ответственность за выбор источников и сохранённые файлы несёт пользователь.
